# School Management System 🏫

A role-based school management application built with **Kotlin, Jetpack Compose, and FastAPI** to bring everyday school activities into one place for administrators, teachers, students, and parents.

## Features

- **Role-based access** for administrators, teachers, students, and parents.
- **Attendance management** for recording and reviewing student attendance.
- **Assignments and study materials** for sharing tasks, notes, and answer files.
- **Fee tracking** for viewing payment status and sending fee reminders.
- **Teacher leave requests** for submitting leave applications.
- **Notifications** for important school updates and reminders.

## Tech Stack

- **Android app:** Kotlin, Jetpack Compose
- **Database:** Firebase, Cloudinary

## Getting Started

### Android app

1. Clone the repository.
   ```bash
   git clone https://github.com/Observer-1729/school_management.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on an emulator or Android device.


## Goals

The project aims to simplify school administration, improve communication between school members, and make attendance, assignments, fee status, and routine requests easier to manage.
